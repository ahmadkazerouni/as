# معلم‌یار — معلم خصوصی هوشمند

نمونه‌ی اولیه‌ی یک سایت معلم خصوصی با هوش مصنوعی برای دانش‌آموزان ایرانی.

## امکانات این نسخه

- صفحه‌ی اصلی با معرفی و **طرح‌های اشتراک**
- **پرداخت نمایشی** (درگاه واقعی هنوز وصل نیست)
- انتخاب **مقطع ← پایه ← درس ← فصل**، یا «**از پایه شروع کن**»
- **کلاس گفتگو** با معلم: توضیح، مثال، سؤال و راهنمایی به روش سقراطی
- **آزمون** چهارگزینه‌ای با نمره و توضیح هر جواب
- **صفحه‌ی پیشرفت** دانش‌آموز
- **تنظیمات هوش مصنوعی**: اتصال به هر سرویس سازگار با OpenAI API (مثلاً Ollama با مدل Qwen)

**کدام هوش مصنوعی پشت معلم است؟** به این ترتیب:
1. اگر در «تنظیمات» سرویس شخصی وارد شده باشد، همان.
2. اگر سایت داخل claude.ai باز شده باشد (برای تست)، خود **Claude** با حساب بیننده.
3. در غیر این صورت **حالت نمایشی**.

معلم جواب‌ها را زنده می‌نویسد، دکمه‌ی توقف دارد، با «امتحان بگیر» امتحان شفاهی می‌گیرد و (داخل Claude) عکس سؤال هم قبول می‌کند. اگر مرورگر صدای فارسی داشته باشد، دکمه‌ی 🔊 جواب‌ها را بلند می‌خواند.

در حالت نمایشی: فصل ۱ ریاضی نهم (مجموعه‌ها) یک درس آماده و یک آزمون ۵ سؤالی دارد.

## اجرا روی کامپیوتر

فایل `index.html` را در مرورگر باز کنید. یا در پوشه‌ی پروژه:

```bash
python3 -m http.server 8000
# بعد برو به http://localhost:8000
```

## انتشار روی اینترنت با GitHub Pages (رایگان)

1. در صفحه‌ی همین مخزن روی **Settings** بزنید.
2. از منوی کنار، **Pages** را انتخاب کنید.
3. در بخش **Build and deployment**، گزینه‌ی Source را روی **Deploy from a branch** بگذارید.
4. شاخه‌ی **main** و پوشه‌ی **/(root)** را انتخاب کنید و **Save** بزنید.
5. بعد از یکی دو دقیقه سایت در این آدرس بالا می‌آید:
   `https://ahmadkazerouni.github.io/as/`

## ساختار فایل‌ها

| فایل | کار |
| --- | --- |
| `index.html` | اسکلت صفحه |
| `css/styles.css` | ظاهر سایت (راست‌به‌چپ، حالت روشن و تیره) |
| `js/data.js` | مقطع‌ها، درس‌ها، فصل‌ها، درس نمایشی، آزمون‌ها و طرح‌ها |
| `js/tutor.js` | موتور معلم: حالت نمایشی و اتصال به هوش مصنوعی |
| `js/app.js` | صفحه‌ها و مسیریابی |

برای اضافه کردن درس یا آزمون جدید، فقط `js/data.js` را ویرایش کنید.

## مراحل بعدی برای نسخه‌ی واقعی

1. **سرور (Backend)**: کلید API و درخواست‌های هوش مصنوعی باید از سرور رد شوند، نه مرورگر.
2. **ثبت‌نام و ورود** با شماره‌ی موبایل و کد پیامکی.
3. **درگاه پرداخت** ایرانی (مثل زرین‌پال). برای این کار معمولاً نماد اعتماد الکترونیکی (اینماد) لازم است.
4. **مدل هوش مصنوعی** قابل استفاده در ایران: مدل متن‌باز روی سرور داخلی، یا یک سرویس API ایرانی.
5. **محتوای درسی** همه‌ی فصل‌ها و آزمون‌های بیشتر.
6. **ارسال عکس سؤال** و حل آن.
7. **گزارش هفتگی برای والدین** با پیامک.
8. **اپ موبایل** (مثلاً با Expo) و انتشار روی TestFlight.
