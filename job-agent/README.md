# Job Agent — ایجنت اپلای خودکار برای مشاغل Product در آلمان

هر ۳۰ تا ۶۰ دقیقه:

1. در **LinkedIn** (جست‌وجوی عمومی، بدون لاگین) آگهی‌های جدید Product در آلمان را پیدا می‌کند.
2. آگهی‌های **Easy Apply را رد می‌کند** و فقط آن‌هایی را نگه می‌دارد که به سایت خود شرکت می‌روند.
3. با **Claude** آگهی را با پروفایل شما مقایسه و امتیازدهی می‌کند (۰ تا ۱۰۰).
4. برای آگهی‌های مناسب، **رزومه و کاورلتر مخصوص همان شغل** (به زبان آگهی: آلمانی یا انگلیسی) می‌سازد و PDF می‌کند.
5. با یک مرورگر خودکار به **سایت شرکت** می‌رود، فرم را پر می‌کند، رزومه را آپلود می‌کند و **ارسال** می‌کند.
6. نتیجه را با **تلگرام** (رزومه + کاورلتر + اسکرین‌شات) برایتان می‌فرستد.

## قوانین ایمنی داخلی

- هیچ اطلاعاتی **از خودش نمی‌سازد**. فقط از `profile/master_profile.md` و بخش `application_facts` در `config.yaml` استفاده می‌کند.
- اگر فرم سؤال اجباری‌ای داشته باشد که جوابش را ندارد، **ارسال نمی‌کند** و از شما می‌پرسد (✋).
- وقتی سایت **کپچا** دارد یا **ساختن اکانت** می‌خواهد، ارسال نمی‌کند و لینک و فایل‌های آماده را برایتان می‌فرستد.
- برای تعداد اپلای در هر اجرا و در هر روز سقف تعیین شده است.
- حالت پیش‌فرض `dry_run` است: فرم را پر می‌کند ولی **دکمه‌ی آخر را نمی‌زند** و اسکرین‌شات می‌فرستد. وقتی از کیفیت راضی بودید، `mode: auto` کنید.

## نصب (روی سرور یا کامپیوتر شخصی)

```bash
git clone https://github.com/ahmadkazerouni/as.git
cd as/job-agent
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
playwright install --with-deps chromium

cp .env.example .env               # ANTHROPIC_API_KEY و توکن تلگرام را وارد کنید
cp config.example.yaml config.yaml # جاهای TODO را پر کنید
```

سپس `profile/master_profile.md` را کامل کنید، به‌خصوص دستاوردها با عدد و رقم. کیفیت رزومه‌ها مستقیماً به این فایل بستگی دارد.

## اجرا

```bash
python main.py --once   # یک بار (برای تست)
python main.py          # همیشه، هر ۳۰ تا ۶۰ دقیقه
```

برای اجرای دائمی روی سرور لینوکس (مثلاً با `tmux` یا systemd):

```bash
tmux new -s jobs 'cd ~/as/job-agent && .venv/bin/python main.py'
```

## تلگرام

1. در تلگرام به `@BotFather` پیام بدهید، دستور `/newbot` را بزنید و توکن را در `TELEGRAM_BOT_TOKEN` بگذارید.
2. به ربات جدیدتان یک پیام بدهید.
3. شناسه‌ی چت خود را از `@userinfobot` بگیرید و در `TELEGRAM_CHAT_ID` بگذارید.

## فایل‌ها

| مسیر | کاربرد |
|---|---|
| `main.py` | حلقه‌ی اصلی و زمان‌بندی |
| `agent/linkedin.py` | جست‌وجو و خواندن آگهی‌ها از LinkedIn، پیدا کردن لینک سایت شرکت |
| `agent/llm.py` | همه‌ی تماس‌ها با Claude: امتیازدهی، ساخت رزومه، پر کردن فرم |
| `agent/resume.py` | ساخت PDF رزومه و کاورلتر |
| `agent/apply.py` | مرورگر خودکار برای پر کردن و ارسال فرم |
| `agent/store.py` | پایگاه داده‌ی SQLite تا به یک آگهی دو بار اپلای نشود |
| `data/` | رزومه‌ها، اسکرین‌شات‌ها و دیتابیس (در git ذخیره نمی‌شود) |

## محدودیت‌ها

- سایت‌هایی مثل Greenhouse، Lever، Personio، SmartRecruiters و Join معمولاً خوب کار می‌کنند.
- سایت‌هایی مثل Workday و SuccessFactors که ساختن اکانت می‌خواهند، به تلگرام شما فرستاده می‌شوند تا دستی اپلای کنید.
- اگر LinkedIn موقتاً درخواست‌ها را محدود کند (خطای 429 یا 999)، ایجنت صبر می‌کند و دوباره تلاش می‌کند.
- هزینه‌ی Claude API تقریباً برای هر آگهی که امتیاز بالا بگیرد حساب می‌شود (امتیازدهی ارزان است، ساخت رزومه و پر کردن فرم گران‌تر است).
